# MAFALDA: ¿TODO BIEN? 🎮

Un mini-RPG fanmade inspirado en los videojuegos japoneses clásicos de los años 90, con Mafalda y sus amigos.

## Jugar

Abrí el archivo [index.html](./index.html) en tu navegador, o activá GitHub Pages en la configuración del repositorio para que se pueda jugar desde una URL pública.

**Duración estimada:** 15–20 minutos.

## Controles

- **WASD / flechas:** moverse.
- **E / Enter:** interactuar y avanzar los diálogos.
- **1–4:** elegir opciones de combate.
- En celulares, usar los controles táctiles de la pantalla.

## Publicar en GitHub Pages

1. Entrá a **Settings → Pages** del repositorio.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná **main** y **/(root)**, y guardá los cambios.
4. Cuando termine la publicación, el juego debería estar disponible en **https://ianlutzky-maker.github.io/MAFALDA/**.

## Sobre el proyecto

Aventura humorística no oficial realizada como homenaje, con diálogos e historia originales. *Mafalda* y sus personajes pertenecen a sus respectivos titulares de derechos.
